# Student Grade Analyzer

## About the Project
Student Grade Analyzer is a beginner-friendly Python project that analyzes student grades, calculates averages, determines pass/fail status, and identifies the highest and lowest-performing students.

The program generates a text report containing individual student results and overall class statistics.

## Features
- Calculate each student's average grade.
- Determine pass or fail status using a passing threshold of 60.
- Calculate the class average.
- Identify the student with the highest average.
- Identify the student with the lowest average.
- Validate grades to ensure they are between 0 and 100.
- Save the analysis results to a text file.
- Handle an empty student list.

## Technologies
- Python 3
- Python built-in functions and file handling

## Concepts Practiced
- Variables and data types
- Lists and dictionaries
- `for` loops and conditional statements
- Functions and return values
- Data validation
- File handling with `open()` and `with`
- Basic data analysis

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open `student_grade_analyzer.py` in Python IDLE or another Python editor.
4. Run the program.
5. Open `student_report.txt` to view the results.
